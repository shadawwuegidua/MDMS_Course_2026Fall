- 建立项目独立 `.venv`，安装并锁定实际依赖。
- 使用 Python 3.12.7、Flask 3.1.3、PyMongo 4.19.0、MongoDB 8.3.11；配置文件读取使用 python-dotenv 1.2.4。
- 建立最小网页程序，提供首页和 `/health` 连接检查。
- 初始化 `users`、`surveys`、`responses` 三个集合、基础字段校验和必要索引。
- 使用项目内独立数据目录启动 MongoDB，监听 `127.0.0.1:27017`；网页监听 `127.0.0.1:5000`。
- 保存运行说明、配置示例、schema 和数据库设计说明。
